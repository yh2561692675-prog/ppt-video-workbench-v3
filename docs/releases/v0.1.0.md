# PPT Video Workbench v0.1.0 source preview

This is the first public source prerelease of PPT Video Workbench, a local-first and auditable workflow for turning presentations and supporting documents into narrated videos.

## Included

- FastAPI and React workbench covering source import, narration, local audio, subtitles, timeline editing, preview, rendering jobs, and auditable artifacts.
- Deterministic Python, frontend, contract, and browser tests on GitHub Actions.
- MIT license, bilingual project overview, contribution guidance, private vulnerability reporting, Issue forms, and PR review guidance.
- Optional external-provider integration behind explicit configuration; the local editing and local-audio workflow does not require an API key.

## Verification

The release workflow requires the checked-in `0.1.0` version in the Python and JavaScript packages and successful default-branch Ubuntu and Windows quality jobs.

## Known limitations

- This is a source prerelease, not a signed Windows installer release.
- Windows installer, GUI installation, real-project rendering, antivirus checks, recovery, and operator sign-off remain pending manual acceptance.
- Do not interpret automated synthetic-fixture tests as completion of those manual release gates.

See `README.md`, `CONTRIBUTING.md`, `SECURITY.md`, and `docs/maintainer-guide.md` before installing, contributing, or reporting a problem.
