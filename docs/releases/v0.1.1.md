# PPT Video Workbench v0.1.1

v0.1.1 is a source security patch release for the public MIT-licensed repository.

## Security and dependency maintenance

- Upgraded the synchronized Remotion package suite to 4.0.507.
- Upgraded both Vitest workspaces to 3.2.6.
- Upgraded React Router to 7.18.2 and Vite to 7.3.5.
- Upgraded FastAPI to 0.139.2 and pinned the directly used Starlette runtime to 1.3.1.
- Upgraded Playwright to 1.55.1.
- Reduced open Dependabot alerts from 49 to one documented low-severity esbuild advisory; critical, high, and medium alerts are zero.
- Confirmed zero open secret-scanning alerts.

## Maintainer workflow

- Added protected pull-request checks across Ubuntu, Windows, and macOS contract jobs.
- Added Issue forms, pull-request templates, CODEOWNERS, dependency grouping, and an auditable release workflow.
- Recorded each security change in a focused pull request with full cross-platform validation.

## Artifacts and limitations

This GitHub release publishes the repository source archive at an immutable commit. It does not include or claim a signed Windows installer. Installer signing and manual Windows acceptance remain a separate release gate.

The remaining low-severity esbuild advisory is tracked in Issue #41. Vite 7 officially constrains esbuild to the affected 0.27 line, so the project will resolve it through a tested Vite 8 migration instead of an unsupported dependency override.
