# ADR-001：本地优先、云端可选

- Status: Accepted
- Date: 2026-08-11
- Supersedes: None

## Context

现有产品是 Windows 本地单用户应用。Provider、跨平台和云协作能力必须演进，但不能让登录、网络或云服务成为既有导入、编辑、预览和导出的前置条件。

## Decision

1. 本地项目目录仍是离线工作的权威副本；未启用云同步时行为与当前版本一致。
2. 云能力通过显式配置启用，不存在隐式上传、遥测或后台注册。
3. 登录失败、云端不可用或授权过期只降低云能力，不阻断本地编辑与导出。
4. 同步以不可变 revision、operation log 和内容寻址对象为边界，不直接共享本地数据库文件。
5. 远程渲染必须是可选执行器；本地执行器始终保留为可诊断的回退路径。

## Consequences

需要维护本地 outbox/inbox、同步状态和冲突界面；但可避免网络故障扩大为核心流程故障，并允许云端后续独立部署和灰度。

## Compatibility

默认功能开关关闭。既有项目无需迁移即可打开；只有首次启用云端时生成远程标识和初始 revision。

## Verification

- 断网且无账号时可完成既有端到端流程。
- 网络请求测试证明默认配置不会上传项目、素材、正文或凭证。
- 云端故障注入不改变本地项目文件和导出结果。
