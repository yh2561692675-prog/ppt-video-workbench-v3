# 真人讲解智能同步模式

真人讲解模式把一条包含原声的视频作为全片主时间轴。PPT 页面、字幕、单页特效和真人小窗都跟随这条时间轴；小窗隐藏或降级时，原声不会中断。

## 录制与素材建议

- 使用 MP4 或 MOV，画面建议至少 1280×720，优先恒定帧率 H.264/AAC。
- 保持人声清晰，避免长时间静音、削波、强混响和持续背景音乐。
- 讲解时按 PPT 页序推进。需要返回前页时明确说出页标题，减少自动匹配歧义。
- 原始真人视频可能包含隐私信息。项目目录应放在受控磁盘；交付前检查制作包，删除不需要共享的源素材和日志副本。

## 标准流程

1. 在真人讲解项目中导入视频。系统先验证容器、视频轨、音轨、时长、分辨率和帧率；失败不会改写项目清单。
2. 执行音频提取和逐字识别。分析音频为 16 kHz 单声道 PCM，原视频保持不变。
3. 检查页面匹配。绿色 `auto` 可直接复核；黄色 `review` 允许预览但需人工确认；红色 `blocked` 必须修正后才能发布。
4. 调整页面锚点的开始/结束时间，点击“保存并锁定”。每次修改携带当前 revision；若出现 409，先刷新并比较差异，系统不会静默覆盖。
5. 检查小窗布局。系统优先避开关键内容和字幕；没有安全位置时自动隐藏小窗，但保留真人原声。
6. 依次预览本页、连续区间和全片低清版本。核对页面切换、字幕、原声和小窗节拍，并记录界面显示的 timeline revision 与 hash。
7. 运行完整预检后导出。制作包应包含 MP4、SRT、转写数据、页面锚点、小窗计划、预检报告、日志和时间线 hash。

## 问题级别

- 红色/`blocking`：源视频缺失、时间线过期、低置信锚点等。必须修复。
- 黄色/`required_warning`：低分辨率、可变帧率或待复核锚点。确认风险后可继续预览；发布前应处置。
- 信息项：不阻断，仅用于定位和追踪。

每个真人问题都有稳定 code、级别、时间范围、页面、原因、修复动作和阻断标记。报告中不使用无法自动处理的纯自由文本错误。

## 安全降级

若某段真人画面解码或合成失败，系统把相交的小窗片段改为 `hidden`，重新渲染 PPT 与字幕，并继续复用同一真人主音轨。结果标记为 `degraded`，报告登记 `PRESENTER_LAYER_RENDER_FAILED`、失败时间范围和建议动作。降级不会伪装成完整成功；修复素材后可局部重渲染。

## 常见错误

- `PRESENTER_AUDIO_MISSING`：视频没有可用音轨，换用含原声的视频。
- `PRESENTER_DECODE_FAILED`：文件损坏或编码不受支持，转码为 H.264/AAC 后重试。
- `PRESENTER_TIMELINE_MISSING`：完成识别、匹配和时间线生成。
- `PRESENTER_TIMELINE_STALE`：源视频已更换，保留人工锁定并重新计算。
- `PRESENTER_ANCHOR_BLOCKED`：修正页码或时间边界并锁定。
- 409 revision conflict：刷新项目，比较服务器版本后重新提交，不要反复覆盖。

## 恢复与缓存

媒体探测、音频提取、ASR、匹配、锚点、布局和分页渲染都有原子检查点。异常退出后从最近安全阶段恢复；修改小窗样式只重建布局与成片，修改页面文字从匹配开始重建，更换源视频从转写开始重建。所有失效计划都保留人工锁定。
