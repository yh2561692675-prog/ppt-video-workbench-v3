# PPT 视频工作台用户手册

这是一套本地运行的 PPT 转讲解视频工作台。项目文件、音频缓存、配置和导出包都留在本机；只有你主动配置并调用的 LLM 或 HeyGen 服务会接收对应请求内容。第一次使用前，请先阅读 [接口配置说明](api-setup.md)，遇到阻断请查看 [排障手册](troubleshooting.md)。

## 安装与首次启动

Windows 10/11 上双击安装包，推荐使用默认的当前用户安装目录。安装不要求管理员权限。安装完成后，从开始菜单或桌面打开 **PPT Video Workbench**。启动器会选择一个空闲的本机端口，等待 `/api/health` 返回成功后打开浏览器；服务只监听 `127.0.0.1`。

卸载只删除程序目录，不删除 `workspace-data` 中的项目、设置和日志。若要迁移到另一台电脑，请先在项目中心确认项目目录和制作包已复制完成。

## 七步制作流程

1. **导入素材**：创建项目，导入 PPTX、DOCX、PDF 或图片。系统会复制并记录安全文件名、大小和 SHA-256。
2. **解析与匹配**：执行材料解析，确认页面顺序、标题和页面文字与讲解提纲的匹配结果。低置信度匹配必须人工确认。
3. **生成/编辑旁白**：可用本地编辑，或在 [接口配置说明](api-setup.md) 中配置 LLM 后生成候选稿。每次修改都会形成 revision；进入音频前确认当前版本。
4. **制作音频**：选择本地录音或 HeyGen。一个项目只能保持一条音频路线；本地录音可以导入、转写、比较差异和调整分页线，HeyGen 页面音频会记录声音参数与 revision。
5. **字幕与音频门禁**：执行转写和字幕构建。词级时间戳会生成字幕时间轴 JSON 与 SRT。处理所有差异、确认旁白和分页边界后，音频门禁才会放行。
6. **效果预览与完整预检**：预览使用整页科技风模板，系统会尝试把字幕放在顶部、中部或底部安全区；都冲突时使用半透明底板。运行完整预检并处理阻断项；允许确认的提醒需要在页面上明确确认。
7. **渲染与导出**：点击“开始渲染与导出”。系统按页面缓存增量渲染，合成 MP4，并导出 SRT、旁白 DOCX、分页音频、Remotion 配置、预检报告、日志和 SHA-256 清单。导出结果会回写项目清单。

## 最终渲染异步任务

最终渲染会提交到本地 SQLite 任务队列，由单一渲染工作器顺序执行。页面会显示排队、渲染、暂停、取消、失败和完成状态，并每秒刷新运行中的任务。暂停只在当前页面或 FFmpeg 阶段到达安全点后生效；取消会终止外部进程并保留已完成的页面缓存。

同一项目同一输入只会保留一个活动任务。失败或取消后可以点击“重试”创建新运行；成功任务会复用已校验的结果。最终 MP4 以原子方式切换，制作包按任务版本保留，旧成功包不会被新失败覆盖。

## 音频路线选择

### 本地录音路线

在第 4 步导入 WAV/MP3 等录音，等待音频分析完成，再运行转写。转写差异有四种处理方式：接受录音、修改旁白、重新导入或标记不确定。分页线保存后会重新刷新项目状态和字幕门禁，避免页面显示旧结果。

### HeyGen 路线

先在设置中保存 HeyGen 配置，再为页面选择声音并生成。密钥只由本机安全存储，页面和导出包不会显示密钥。相同页面、相同 revision 和相同声音参数的历史缓存可以无付费回填；更换声音或旁白必须显式确认“替换本页”。混用本地录音和 HeyGen 会在远程请求前被阻止。

## 预检、恢复与缓存

预检结果、输入指纹、确认记录和导出结果都写入项目清单与日志。重新打开项目时，工作台会读取最近一次可审计状态；输入发生变化会让旧报告失效。长任务会保存检查点，应用关闭后重新打开可继续或重试失败页。

缓存只保存可重建产物。项目中心的“缓存清理”会先列出路径、预计释放空间和受影响节点；确认后才删除。源文件、当前项目清单、设置和已导出的最终制作包受保护。

## 更新与回滚

进入“设置 → 更新与恢复”检查 stable 版本。更新会显示版本、说明和大小，先下载并校验，再点击“确认应用更新”。应用前自动备份设置与工作区索引，项目目录不会移动。新版本迁移或健康检查失败会自动切回上一版本；也可以在同一页面手动回滚。
