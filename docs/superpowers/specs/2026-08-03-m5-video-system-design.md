# M5 字幕与视频系统设计

## 目标

在 M4 已通过音频门禁的基础上，建立从 `PageAudio[]`、旁白和页面预览到字幕、浏览器预览、分页渲染及完整制作包的本地闭环。标准项目必须能够预览并输出页面时长与音频一致的 16:9 MP4 与 SRT，且所有关键状态可审计、可重试、可复用。

## 范围与不变约束

- 本轮只实现 Task 22—26，不提前实现 M6 的扩展能力。
- 页面模型、音频时间轴模型和渲染 Props 在视觉模板并行前冻结。
- 继续复用 M4 的统一 `PageAudio[]` 与字幕门禁；未通过音频门禁不能进入字幕、预览或渲染。
- 画布固定为 1920×1080、16:9；页面保持等比显示，不裁切核心内容。
- 复杂视觉采用整页预览图叠加 Remotion 效果，不拆解 PPT 内部元素。
- 旁白、页面时长、音频文件、字幕时间轴和渲染缓存都绑定版本或哈希，过期结果不能静默复用。
- 不把凭证写入 manifest、JSON 响应、导出包或日志；远程服务仍沿用 M4 的安全边界。

## 任务划分

### Task 22：字幕与 SRT

新增字幕模型和字幕服务，以已确认旁白、`Transcript` 的词级时间戳、`PageAudio[]`/页面时间轴生成 `SubtitleCue[]`。字幕必须按页面边界裁剪、时间单调、无重叠，并保留页码和词级来源。生成 `06_字幕/字幕时间轴.json` 与 `06_字幕/字幕.srt`，SRT 使用标准 `HH:MM:SS,mmm` 时间格式。缺少词级证据时阻断，不猜测时间。

### Task 23：Remotion 参数契约

冻结 Python 与 TypeScript 共享语义的 `ProjectVideoProps`：项目标识、画布参数、页面列表、页面预览图、页面起止时间、字幕 cue、音频路径、模板版本和 reduced-motion 设置。以 fixture 与契约测试保证 Python JSON、TypeScript 类型和 Remotion 组合的字段一致；帧数由毫秒时间轴使用明确的四舍五入规则换算。

### Task 24：科技风模板

实现可复用的 16:9 科技风组合：整页画面推拉、轻微前向网格、扫描线、中心雾化、聚焦框、关键词发光和页面转场。动画只使用页面级数据和字幕 cue，不覆盖正文关键区域；保留 5% 画布安全区、底部字幕安全区和 `prefers-reduced-motion`/Props 开关。模板版本进入渲染缓存键。

### Task 25：预览工作台与字幕避让

提供后端预览会话/预检接口及前端第 6 步工作区。预览使用与最终渲染相同的 Props；根据页面文字占用区域选择字幕位置，若所有候选位置均冲突则使用半透明底板并报告原因。工作台支持按页跳转、播放/暂停、字幕样式与动画开关、当前页问题定位；第 7 步仍受预检门禁控制。

### Task 26：分页渲染与完整制作包

按页面缓存键增量渲染，随后用 FFmpeg 合成 H.264/AAC MP4，并输出 SRT、旁白确认版 DOCX、分页音频、Remotion 工程、Props/配置、预检报告和日志清单。单页失败只重渲染失败页；缓存命中页面不得重复处理。导出包必须有固定目录、清单和 SHA-256，缺失文件或时长不一致时阻断交付。

## 数据流

```text
M4 AudioGate
    -> PageAudio[] + confirmed narration + page previews
    -> SubtitleService
    -> SubtitleCue[] + SRT + subtitle timeline JSON
    -> ProjectVideoProps
    -> Remotion preview / page render
    -> FFmpeg composition
    -> MP4 + complete production package
```

## 错误与门禁

- 音频门禁未通过：返回逐页阻断原因，不生成字幕或渲染任务。
- 旁白、音频、页面预览或 Props 版本不一致：标记缓存过期，要求重新生成，不静默覆盖。
- 词级时间戳缺失、越界、逆序或页面无音频：阻断字幕时间轴。
- 字幕避让失败：允许半透明底板兜底，但必须在预检报告中记录。
- FFmpeg、Remotion 或单页输出失败：保留失败页日志和可重试状态，不宣称制作包完成。
- 任何外部服务错误都映射为不含密钥的可操作错误；本地测试使用 fake 服务，真实付费调用保留 Windows 实机补充验收。

- Task 23 覆盖双端 Props fixture、尺寸/FPS、毫秒到帧数、未知字段阻断。
- Task 24 覆盖模板渲染、页面级动画、字幕安全区、reduced-motion 和不拉伸。
- Task 25 覆盖预检阻断、字幕避让、底板兜底、逐页跳转与刷新后状态一致。
- Task 26 覆盖增量缓存、FFmpeg 合成、时长校验、完整制作包、失败页单独重试。
- M5 Gate 需通过 Python、前端、Remotion 类型/测试、契约快照、生产构建、Playwright 生命周期和至少一条 8 页 fake/fixture 端到端视频链路。
- Windows 实机补充项单独记录：真实 FFmpeg、长项目渲染、人工试听、H.264/AAC 播放、中文路径及 GPU/CPU 资源表现；自动化 fake 证据不替代实机证据。
