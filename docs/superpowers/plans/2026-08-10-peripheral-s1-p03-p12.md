# Peripheral S1 P03-P12 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将现有 PPT Video Workbench 制作链迁移为 S0 托管的 P03—P12 独立业务模块，同时保持主程序对项目状态的唯一控制和原流程可降级运行。

**Architecture:** 主程序的 S1 协调器冻结输入并提交版本化任务，S0 负责任务生命周期和工件发布，P03—P12 独立进程复用现有 `workbench` 领域服务。成功结果通过严格业务结果清单和流式工件接口返回，由类型化投影器原子写入 `ProjectManifest`；外围不可用时按模块开关回退现有本地路径。

**Tech Stack:** Python 3.12、FastAPI、Pydantic 2、SQLite/SQLAlchemy、httpx、pytest、PyInstaller、React 19、TypeScript、TanStack Query、Vitest、Playwright、Remotion、FFmpeg/ffprobe、LibreOffice、PaddleOCR、faster-whisper、HeyGen/OpenAI-compatible API。

## Global Constraints

- `ProjectManifest` 和 `project.json` 只能由主程序存储服务写入，任何业务模块不得直接修改。
- S0 SQLite 只保存任务、attempt、事件和工件元数据，不复制完整项目业务状态。
- Host 与适配器只允许 `http://127.0.0.1:<port>` 或 `http://localhost:<port>`。
- 输入、结果和事件契约主版本固定为 `1.0`；未知字段必须拒绝。
- 输入只允许工作区内相对路径；拒绝盘符、UNC、`..`、ADS、符号链接和重解析点逃逸。
- 已发布工件不可覆盖；每次物化都校验字节数和 SHA-256。
- 自动重试最多三次，退避固定为 5、30、120 秒；付费任务重试前查询远端 request ID。
- 密钥、Authorization、Cookie、JWT、旁白正文、完整用户路径和模块 stderr 不进入事件、错误、检查点或诊断包。
- P07 本地录音与 HeyGen 路线严格互斥；P06 当前 revision 未全部确认时禁止进入 P07。
- P10 阻断项未清零、确认项未审计时禁止 P11；P12 自动通过不能替代要求的人工签署。
- S1 首版保持单 worker；只有性能证据证明资源隔离安全后才增加并发。
- S0 Windows G5 未形成真实 PASS 证据前，S1 不进入发布候选。
