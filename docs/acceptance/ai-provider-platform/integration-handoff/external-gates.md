# 外部与人工 Gate

以下项目不能由本地测试数量、fixture 或 fake adapter 代替：

| Gate               | 当前状态   | 需要的真实证据                                                                      |
| ------------------ | ---------- | ----------------------------------------------------------------------------------- |
| Windows 最终候选   | 待复验     | 干净提交绑定的安装、中文/长路径、断网、本地渲染、回滚/重装和签名证据                |
| 真实硬件模型       | 待验证     | 目标 Windows 硬件上的 CUDA/DirectML、Faster-Whisper、真实 TTS probe 与质量/资源记录 |
| 真实供应商 sandbox | 待验证     | 非生产凭证、预算上限、异步恢复、webhook、费用对账与供应商 conformance               |
| 付费操作           | 待明确授权 | 明确 Provider、最大预算、授权人、可回滚 canary 和账单核对                           |
| 声音授权与音画审核 | 待人工签署 | 本人/被授权主体范围与有效期、样本哈希、旁白/字幕/音画人工审核                       |

本地功能默认 opt-in；没有凭证时不执行远端付费服务，没有真实授权样本时不训练、克隆或云端上传声音。
