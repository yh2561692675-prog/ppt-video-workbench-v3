# PPT Video Workbench M8 RC1 V3 - Windows Rebuild

## Why this package replaces V1 and V2

The previous Windows package could install a Web UI without the API executable.
The actual cause was in `apps/api/workbench.spec`: the project root was resolved
one directory too high, so PyInstaller looked outside the source checkout for
`desktop.py` and did not produce `workbench.exe`.

V3 fixes that source path and adds two release gates:

1. The build stops immediately if PyInstaller does not create
   `dist/release/api/workbench.exe`.
2. Inno Setup cannot run unless the API executable, Web entry page, and runtime
   manifest all exist in the release stage.

## Build a new installer

1. Extract this archive to a new folder, for example:

   `F:\ppt-video-workbench-v3`

   Do not extract it over the old `F:\ppt-video-workbench` folder.

2. Open PowerShell and run:

   ```powershell
   Set-Location "F:\ppt-video-workbench-v3"
   Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
   .\scripts\build-release.ps1
   ```

   The script automatically finds Inno Setup in either the system installation
   directory or the current Windows user's local installation directory.

3. Before running the installer, verify all four commands return `True`:

   ```powershell
   Test-Path ".\dist\release\api\workbench.exe"
   Test-Path ".\dist\release\web\index.html"
   Test-Path ".\dist\release\runtime-manifest.json"
   Test-Path ".\release\ppt-video-workbench-setup.exe"
   ```

4. Run the newly generated installer:

   ```powershell
   Start-Process "F:\ppt-video-workbench-v3\release\ppt-video-workbench-setup.exe"
   ```

   Keep the installer default destination. If a broken earlier installation is
   still listed in Windows Settings, uninstall it first, then run this installer.

5. After installation, verify the installed payload before launching:

   ```powershell
   $root = "$env:LOCALAPPDATA\PPTVideoWorkbench\app"
   Test-Path "$root\release\api\workbench.exe"
   Test-Path "$root\release\web\index.html"
   Test-Path "$root\scripts\launcher.ps1"
   ```

   All three commands must return `True`. Then start PPT Video Workbench from
   the Start menu or desktop shortcut.

## If a command fails

Do not run the installer when any build verification command returns `False`.
Copy the complete PowerShell output from the first error through the prompt;
the release gates are designed to identify the missing stage directly.
