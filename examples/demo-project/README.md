# 星港数据安全入门演示项目

这是一个 8 页的合成演示项目，用于验证项目清单读取、旁白编辑、字幕、预检和制作包导出流程。页面文字、旁白和 `synthetic:demo` 引用均为示例内容，不依赖外部服务，也不包含真实素材。

## 使用方式

1. 在项目中心导入本目录中的 `project.json`，或根据清单新建同名项目。
2. 按 [用户手册](../../docs/user-guide.md) 的七步流程检查页面顺序和旁白。
3. 在第 4 步选择本地录音；如果只验证 UI，可继续使用空音频状态并观察门禁提示。
4. 在第 6 步运行预检，确认安全区和字幕避让提示。
5. 在第 7 步导出后，预期制作包包含 MP4、SRT、旁白 DOCX、分页音频、Remotion 配置、预检报告、日志和 SHA-256 清单。

清单文件可直接用 `project.json` 查看，所有页面按 1–8 排序，便于测试分页、缓存和失败页重试。
